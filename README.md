# Calamity Craft

Minecraft 1.20.1 + Forge 47.4.10. Oculus and shaderpacks included.

Download all .zip.001/.zip.002 parts, Extract.bat and Join-and-extract.ps1 into one folder. Run Extract.bat, then Minecraft/Calamity Craft/Start Minecraft.bat. Alternatively join the parts with 7-Zip. Sign into your own launcher account.

Launcher account files, logs and disabled mods are excluded. Game launch on another PC has not been tested.
